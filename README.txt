# Luminous Ink by M.L. — Homepage Prototype 1

This is a first responsive homepage prototype for Luminous Ink.

## Files
- `index.html` — homepage structure, styling, and small navigation script
- `logo.png` — prepared copy of the supplied Luminous Ink logo

## Preview
Open `index.html` in a browser. Keep `logo.png` in the same folder.

## Current scope
This is a visual prototype. The library is intentionally an empty placeholder until M.L.'s real books are added. No accounts, payments, or book uploads are connected yet.

## Brand
- Name: Luminous Ink
- Byline: M.L.
- Tagline: Silence, Put Into Words.
- Palette: midnight black, champagne gold, warm ivory
